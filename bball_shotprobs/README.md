This work describes a methodology to predict NBA shot probability and translate it into player skill. The first iteration, v1's writeup, was a school project a classmate and I worked on. We predicted shot probability based on distance and angle using Bayesian Additive Regression Trees (BART), then layered in hierarchical random effects for players, defenses, and teams. We structured the player effects as a random walk to learn their latent skill. While this model passed the eye test, it was not a projection model, used only three seasons of data, and did not account for correlation between shot type.

In v2, I expanded the dataset to five seasons, 2021/22 to 2025/26, which resulted in over a million shots in the dataset. Given the expanded dataset, I ran out of computational power for BART and pivoted to frequentist methods, trialing Logistic Regression, Tree Based Methods, and a Neural Network to predict shot probability using distance, angle, and a boolean flag for whether a player attempted the shot behind the backboard. The rest of this project is currently under construction....
